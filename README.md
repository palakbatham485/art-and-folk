# INK & CRAFT — Haute Atelier & Luxury Editorial Art Marketplace

An ultra-premium editorial art marketplace Single Page Application (SPA) inspired by luxury periodicals, fine art institutions, and high-end ateliers. Powered by React, Vite, and Tailwind CSS.

---

## ✨ Features & Architecture

- **Sovereign Escrow & Provenance**: Multi-sig escrow settlement protocol where a 20% earnest deposit is held until physical patron uncrating and ratification.
- **Physical NFC Cryptographic Dualism**: Every masterwork is tied to a physical tamper-evident NFC capsule and an immutable ledger deed.
- **Dynamic Catalogue & Faceted Filter Rail**: Real-time search across artists, media, and titles with facets for Craft Discipline, Price Brackets, and Availability.
- **Product Experience (PDP)**:
  - Multi-angle inspection switcher (Master Work, Texture Detail, In-Situ Living, Verso & Seal).
  - Augmented Reality (AR) in-situ wall visualizer simulator.
  - High-resolution macro zoom texture inspection.
  - Interactive postal pincode delivery route validator.
  - Atelier custom framing selection with real-time recalculation.
  - Private curatorial consultation modal.
- **Acquisition Bag & B2B Tax Compliance**:
  - Live bag quantity adjusters and Patron Vault bookmarking.
  - Corporate GSTIN & Legal Entity validation eligible for Input Tax Credit (ITC).
- **Secure Escrow Checkout & Settlement**:
  - Patron residence selector (South Mumbai, Manhattan, Alibaug).
  - Armored logistics tier selection with climate telematics.
  - Settlement node selection (Multi-Sig Escrow, RTGS/Fedwire, Encrypted Private Card).
- **Provenance Receipt & Exporters**:
  - Real-time downloadable Tax Invoice PDF (browser print).
  - Exportable E-Way Bill & IRN compliance JSON payload.
  - Cryptographic deed verification modal.
- **Dual Sovereign Dashboards**:
  - **Patron & Collector Suite (Buyer)**: 4-step delivery timeline and interactive 80% escrow release button.
  - **Guild Atelier Workspace (Seller/Artisan)**: Inventory management, masterwork submission modal, batch NFC verification scan, and GSTR-1 tax dossier exporter.
- **Sovereign Treasury & FX Hub**:
  - Live settlement currency switcher across **INR (₹)**, **USD ($)**, **EUR (€)**, **GBP (£)**, and **JPY (¥)**.
  - Interactive valuation & tax settlement calculator.
- **Fully Responsive**: Flawless mobile drawer navigation, responsive typography, and tactile planar styling based on the *Atelier Curatorial* design system.

## 🛠️ Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite 6
- **Styling**: Tailwind CSS
- **Fonts**: Playfair Display (Serif) & Plus Jakarta Sans
- **Icons**: Material Symbols Outlined

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
